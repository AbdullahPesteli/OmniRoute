> **Orísun òtítọ́:** `src/lib/guardrails/`
> **Ìmúdójúìwọ̀n tó ṣẹ̀ṣẹ̀:** 2026-08-29 — v3.8.51 (olùpè ló ń kéde orísun transcript Video Bridge,
> olupin kò tíì jẹ́rìí rẹ̀ — a ti mú un ṣe kedere gẹ́gẹ́ bí #11661)

Àwọn guardrail ń fipá mú ààbò, ìlànà, àti àwọn ìyípadà àkóónú ṣiṣẹ́ ní ààlà
láàárín OmniRoute àti àwọn olupèsè upstream. Guardrail kọ̀ọ̀kan lè ṣàyẹ̀wò (àti
ní àṣàyàn, kọ̀, yí padà, tàbí fi àlàyé kún) àwọn payload ìbéèrè (`preCall`) àti
àwọn ìdáhùn upstream (`postCall`).

Ètò náà jẹ́ **fail-open**: bí guardrail kan bá dá àṣìṣe sílẹ̀ nígbà tó ń ṣiṣẹ́, registry
yóò ṣe àkọsílẹ̀ àṣìṣe náà, yóò sì tẹ̀síwájú sí guardrail tó kàn dípò kí
ìbéèrè náà kùnà. Dídènà jẹ́ ìpinnu tí a ṣe ní kedere (`block: true`), kì í ṣe ìṣẹ̀lẹ̀ àìròtẹ́lẹ̀.

### Vision Bridge (`visionBridge.ts`) — Modality Bridge PR-1

N gba awọn ibeere ti o ni aworan ti a fojusi si **awọn awoṣe ti ko ni iran** ki o si
tun tọka gbogbo ibeere si awoṣe ti o ni agbara iran tabi rọpo awọn apakan aworan
pẹlu awọn apejuwe ọrọ ti a ṣe nipasẹ awoṣe iran ti a le ṣe atunṣe ṣaaju
ipe ti o wa loke. Eyi jẹ ki awọn olupese ọrọ nikan mu
multimodal payloads ni kedere.

Ilana:

1. Foju kọ ti awoṣe ibi ti o ti ni atilẹyin iran tẹlẹ (ayafi ti o ba han ninu
   atokọ ti a fi agbara mu `isVisionBridgeForcedModel`).
2. Yọ awọn apakan aworan nipasẹ `extractImageParts(messages)`
   (`visionBridgeHelpers.ts`), eyiti o n fi ẹru si **olutọpa media
   ti a ṣepọ** `detectMediaParts()` ninu `open-sse/utils/mediaParts.ts` — orisun
   otitọ kan ti a pin pẹlu àlẹmọ ibamu combo.
   Yiyọ ni a gba laaye si awọn apakan ipele oke ti awọn apẹrẹ
   `replaceImageParts` le fa pada (adehun extract↔replace): OpenAI
   `image_url`, Anthropic base64 `source.type:"base64"`, Anthropic URL
   `source.type:"url"`, ati Responses API `input_image`. Awọn ikolu ti o wa ni
   inu ati awọn apẹrẹ ti o jẹ ami nikan jẹ ohun elo àlẹmọ combo ati pe a ko
   yọ wọn. Foju kọ ti ko si ti a ri.
3. Yan iṣeto akoko gidi nipasẹ `resolveVisionBridgeRuntimeSettings()`
   (`src/shared/constants/modalityBridgeDefaults.ts`): awọn bọtini iṣeto tuntun `modalityBridge*`
   ṣẹgun; awọn bọtini `visionBridge*` atijọ wa ni **iyipada-ọkan
   pada** (window rollback). Foju kọ ṣaaju eyikeyi irin-ajo media nigbati
   àlẹmọ naa ti wa ni pipade.
4. Oluyanju ipo (`modalityBridgeVisionMode`, wo tabili ni isalẹ) pinnu
   tun tọka vs ṣe apejuwe. Tuntun tọka pada `modifiedPayload` pẹlu `model`
   ti a rọpo, pẹlu meta `{ rerouted, fromModel, toModel, imagesKept }`.
5. Ọna apejuwe: dinku awọn aworan ni `maxImages`, kọ ọrọ-ọrọ ti o ni imọ
   nipa iṣẹ, kan si ibi ipamọ apejuwe, pe awoṣe iran **ni ẹgbẹ**
   (`Promise.allSettled`), ati fi awọn apakan ọrọ `[Image N]: <description>`
   sinu ipo wọn. A ko ni apejuwe ti o kuna `null` ati pe apakan aworan atilẹba
   ni a **pa** (#4012) — ayafi lori ọna apejuwe combo nigbati gbogbo
   apejuwe kuna, nibiti a ti ni idaniloju pe a ko ni iran ti o wa loke
   gba stub `(unavailable — no vision-capable provider connected)` dipo (#8430).
6. Da `modifiedPayload` + meta (`imagesProcessed`, `descriptions`,
   `processingTimeMs`, `visionModel`).

#### Oluyanju ipo (`modalityBridgeVisionMode`)

| Ipo        | Aiyipada | Iwa                                                                                                                                                                                                                                                  |
| ---------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`     | ✔        | Heuristic atijọ, ti ko ni ifọwọkan (#6640/#7204): awọn awoṣe ti ko ni combo/`auto/` n tun tọka si awoṣe iran ti o dara julọ ayafi ti awoṣe atilẹba ba ni awọn iwe-ẹri ti o wulo (nigbana ni apejuwe); awọn ibi-afẹde combo nigbagbogbo n ṣe apejuwe. |
| `describe` |          | Maa ṣe apejuwe nigbagbogbo — a foju kọ bulọọki tun tọka patapata; awoṣe ti olumulo yan nigbagbogbo n dahun.                                                                                                                                          |
| `reroute`  |          | Fi agbara mu tun tọka: a foju kọ aabo awoṣe ti o ni iwe-ẹri. Aabo iwe-ẹri tun-tọka-**ibi-afẹde** ṣi n ṣiṣẹ — nigbati ko si ibi-afẹde iran ti o wulo, ibeere naa n lọ si apejuwe ki awọn aworan aise ko ni de ọdọ backend ti ọrọ nikan (#8430).       |

Awọn ipo ti a fi agbara mu n ṣafihan **ṣaaju** ki heuristic aifọwọyi ṣiṣẹ; iwa `auto`
ni idanimọ byte si awọn guardrail pre-PR-1.

#### Ibi ipamọ API-key (`visionBridgeKeyScope.ts`)

Nigbati bọtini API ti ol caller ba ni ihamọ `allowedConnections`, awọn adagun
(`allowedQuotas`) tabi awọn awoṣe (`allowedModels` / `blockedModels` /
`modelAccessMode: "restricted"` / `disableNonPublicModels`), àlẹmọ naa nikan
yan awọn awoṣe tun tọka ati apejuwe ti bọtini le lo, lori awọn asopọ ti bọtini le
lo. Ipe apejuwe naa lẹhinna nigbagbogbo n lọ nipasẹ OmniRoute self-loop pẹlu
header `x-omniroute-self-loop-key-id`, nitorinaa ibeere iwiregbe ti o gba
n ṣe afihan asopọ ati ilana awoṣe ti bọtini naa lẹẹkansi. `enforceApiKeyPolicy()`
bọwọ fun header yẹn nikan pẹlu bearer self-loop, nitorinaa o le nikan
dinku iraye si, ati id ti ko ni ipinnu ni a kọ.

Ti ko si awoṣe iran ti a gba laaye fun bọtini, ọna apejuwe naa n yọkuro
ati pe ibeere naa n kọja laisi iyipada, iwa kanna ti o ṣii-fail bi
guardrail ti a ti pa (meta `{ skipped: true, reason: "no_permitted_vision_model" }`).
Awọn ibeere laisi bọtini, ati awọn bọtini laisi awọn ihamọ wọnyi, n ṣiṣẹ ni deede bi
ṣaaju.

#### Ọrọ-ọrọ apejuwe ti o ni imọ nipa iṣẹ (`modalityBridgeVisionTaskAware`)

Default **true**. `composeVisionPrompt()` (`visionBridgeHelpers.ts`) nfi
ìtàn àkọ́kọ́ ti **ìfẹ́sẹ̀yìn olùsọrọ** (tí a dín kúrò ní 500 chars) sí àkọ́kọ́
ìtàn àkọ́kọ́, tó ń tọ́ka ìtàn náà sí ohun tí olùsọrọ náà béèrè
(pàtẹ́wọ́ codex-vision-proxy) àti béèrè fún àwòrán àfihàn láti kọ́
ìtàn tó hàn. Pẹ̀lú àfihàn ti a pa — tàbí kò sí ìtàn olùsọrọ — àkọ́kọ́
ìtàn ni a lo láì yí padà.

Ìtàn àkọ́kọ́ ti ara rẹ̀ ti OpenAI-compatible ìbéèrè (`callVisionModelSingle()`
ní `visionBridgeHelpers.ts`) máa ń béèrè `image_url.detail: "high"` —
láìkà, fún gbogbo olùpe/olùpèsè, kò sí àfihàn kankan láti ọdọ
olùsọrọ. Àwọn àpẹẹrẹ kékèké dín ìtẹ́numọ́ OCR kó tó
ìtàn àfihàn tí ìbéèrè yìí béèrè, nítorí náà, ìbéèrè àkọ́kọ́
máa ń béèrè fún àkópọ̀ gíga láìkà ohun tí ìbéèrè àkọ́kọ́
tí wọlé lo. Èyí kan àkọ́kọ́ ìbéèrè àkọ́kọ́; kò yí padà bí
OmniRoute ṣe ń ránṣẹ́ sí `image_url.detail` ti olùsọrọ
ní ìbéèrè àkọ́kọ́ — àfihàn yẹn ni a lo lọ́tọ̀, àti
nìkan fún àwọn olùsọrọ OpenCode tí a rí, ní
`defaultImageDetail()` (`open-sse/handlers/chatCore/upstreamBody.ts`).
Ìtàn àkọ́kọ́ ti Anthropic wire-format ti ìtàn àkọ́kọ́
kò ní `detail` ààyè àti kò ní ipa kankan láti
àfihàn àkọ́kọ́.

#### Àkópọ̀ ìtàn àkọ́kọ́ (`modalityBridgeVisionMaxChars`)

| Key                            | Default | Range              |
| ------------------------------ | ------- | ------------------ |
| `modalityBridgeVisionMaxChars` | `0`     | `0` tàbí 100–50000 |

`0` (àfihàn) túmọ̀ sí **kò sí àkópọ̀** — ìtàn àfihàn tí a
rànṣẹ́ láti `callVisionModel()` ni a ń ránṣẹ́ láì yí padà,
tó ń pa ìhùwàsí tó wà. Ohun tí ó wà nínú 100–50000
yóò dín ìtàn àfihàn kúrò pẹ̀lú `…` àfikún kí ó tó
dá padà gẹ́gẹ́ bí `[Image N]: <description>`
(`VisionBridgeGuardrail.preCall()` ní `src/lib/guardrails/visionBridge.ts`).
Gbé e soke fún àwọn iṣẹ́ OCR tó ní àkópọ̀ gíga
níbi tí àwòrán àtẹ̀jáde nílò ìtàn àfihàn pátápátá; dín e
kúrò láti dín ìlò token ní àwọn àwòrán àfihàn tó ní
ìtàn. Àwọn ààyè àkọ́kọ́ wà lórí taabu Vision
ní panẹ́l Advanced (`modality-bridge-max-chars` ní
`ModalityBridgeVisionTab.tsx`) àti ń dín gbogbo
ìtàn láàárín 1 àti 99 sí ilẹ̀ 100 nígbà tí ó fi
kó `0` sílẹ̀ — `0` jẹ́ àfihàn Zod tó wúlò
(`z.union([z.literal(0), z.number().int().min(100).max(50000)])`), kì í ṣe
àfihàn "ti a ko ṣeto".

#### Àkópọ̀ ìtàn àkọ́kọ́ (`modalityBridge/bridgeCache.ts`)

LRU + TTL àkópọ̀ nínú iranti fún ìtàn àfihàn, tí a pin
ní gbogbo ìlànà. Key = `sha256(imageRef + composedPrompt + configuredBridgeModel)` pẹ̀lú
ìtẹ́numọ́ àkópọ̀ (kò sí ìkànsí ààyè). Ẹ̀ka àwòrán ni
àwòrán àfihàn **tí a ṣeto**, kì í ṣe àwòrán tí ó dáhùn —
`callVisionModel` lè padà sílẹ̀ nínú, àti
kíkọ́ nípa ìgbìmọ̀ kọọkan yóò dín àkópọ̀ kúrò. Àwọn ìtàn àfihàn
tí kò ṣaṣeyọrí kò ní àkópọ̀. Àwọn ààyè:

| Key                             | Default | Range   |
| ------------------------------- | ------- | ------- |
| `modalityBridgeCacheEnabled`    | `true`  | —       |
| `modalityBridgeCacheTtlMinutes` | `60`    | 1–1440  |
| `modalityBridgeCacheMaxEntries` | `200`   | 10–5000 |

#### Àtúnṣe àwòrán àjò (self-loop describe/base64 fetch)

Nígbà tí àgbájọ́ bá n gba àwòrán **àjò** fúnra rẹ̀ — ìtàn àfihàn
Anthropic àti àtúnṣe claude-wire-format base64
(`ensureBase64ImagesForClaudeWire`), mejeji ní
`fetchRemoteImageAsDataUri()` ní `visionBridgeHelpers.ts` — URI data
tí a rí ni a ń ránṣẹ́ láti `normalizeDataUri()`
(`open-sse/utils/imageNormalize.ts`) kí ó tó
dá sí ìbéèrè àwòrán. Àwọn àwòrán tó pọ̀ jù
ni a dín sí **2048px ẹgbẹ́ gíga** (tó bá
àkópọ̀ àtúnṣe OpenAI/Anthropic tí a ti lo ní ẹgbẹ́
ìkànsí), tó dín
ìkànsí/ìkànsí kó tó yí padà ohun tí àwòrán àfihàn rí. Àtúnṣe
nlo `sharp`, tí a gba wọlé pẹ̀lú ìmúpọ̀ àkópọ̀: ní
pẹpẹ̀ kan níbi tí binary rẹ̀ kò le gba wọlé, `normalizeDataUri()` **kò ní
fa** — ó padà sí ìtẹ́numọ́ ti àwọn bytes àkọ́kọ́, nítorí náà,
ìtàn àfihàn/base64-ìtúnṣe
máa ń ṣiṣẹ́. Àwọn bytes tí kì í ṣe àwòrán (ìgbà tí a kò rí
àwòrán tó le yá) ni a tún ránṣẹ́ láì yí padà. Àtúnṣe yìí
ni a fi sílẹ̀ fún àwọn àwòrán tí àgbájọ́ gba fún
ìtàn àfihàn rẹ̀ — kò ní lo fún ìtẹ́numọ́
raw ti olùsọrọ, tó bá jẹ́ pé àfihàn
ìyípadà tó ní àfihàn (Hard Rule #20).

#### Àtẹ̀jáde àyípadà + àtúnṣe

Àwọn bọtini tuntun `modalityBridge*` ni a ṣàyẹ̀wò
nínú `updateSettingsSchema`
(`src/shared/validation/settingsSchemas.ts`): `modalityBridgeVisionEnabled`,
`modalityBridgeVisionMode`, `modalityBridgeVisionModel`,
`modalityBridgeVisionTaskAware`, `modalityBridgeVisionPrompt`,
`modalityBridgeVisionTimeout`, `modalityBridgeVisionMaxImages`,
`modalityBridgeVisionMaxChars`, ẹgbẹ́ `modalityBridgeCache*`, àti
ẹgbẹ́ `modalityBridgeAudio*` tí a lo ní Audio Bridge. Àtúnṣe
`141_modality_bridge_settings.sql` ń da àwọn
àfihàn àtijọ́ `visionBridge*` sí àwọn bọtini tuntun
tó bá mu (idempotent, kò ní kọ́
àfihàn `modalityBridge*` tí olùsọrọ ṣeto); àwọn bọtini àtijọ́
máa ń gba gẹ́gẹ́ bí àtúnṣe àyípadà fún
ìkànsí kan.

#### Àtẹ̀jáde ìmọ̀lára + ìṣirò

Ìtàn àfihàn tí a yí padà ní
`x-omniroute-modality-bridge: image->text;model=<visionModel>;parts=<n>`
(tí a kọ́ ní `buildModalityBridgeHeader()` ní `modalityBridge/bridgeStats.ts`,
tí a fi ẹ̀sùn sí `withModalityBridgeHeader()` ní `src/sse/handlers/chatHelpers.ts`).
Àwọn ìbéèrè tí a tún ránṣẹ́ kò ní **àtẹ̀jáde** — àkópọ̀ náà
kò yí padà àti àtúnṣe àwòrán ti wà ní
àkópọ̀ ìtàn.

`GET /api/modality-bridge/stats` (iṣẹ iṣakoso auth, ipele kanna bi
`GET /api/settings`) n pada awọn kaunti per-modality ti o wa ni iranti
`{ attempts, successes, bridged, cacheHits, failures, totalLatencyMs,
latencySamples, averageLatencyMs, lastUsedAt }` fun `vision`, `audio`, ati
`video`. `averageLatencyMs` n lo `latencySamples`, kii ṣe gbogbo awọn igbiyanju, gẹgẹbi
denominator rẹ; iṣẹ kan laisi akoko ko ṣẹda ayẹwo milisẹkẹndu odo. `bridged` wa bi
alias ti o ni ibamu pẹlu ẹyọkan fun awọn iyipada ti o ni aṣeyọri; awọn igbiyanju ti o kuna ko
mu ki o pọ si.
Awọn kaunti tun bẹrẹ lori atun bẹrẹ ilana nipasẹ apẹrẹ
(telemetry, kii ṣe iṣiro).

### Audio Bridge (`audioBridge.ts`) — Modality Bridge PR-3

N gba awọn ibeere iwiregbe ti o ni audio ṣaaju ki wọn to de ibi-afẹde ti ko
mọ lati gba input audio. Ko tun yipada ibeere iwiregbe: awọn apakan audio ni
a kọ silẹ nipasẹ ipinnu OpenAI ti o wa tẹlẹ ati awoṣe iwiregbe ti a yan n tẹsiwaju pẹlu awọn akọsilẹ ọrọ.

Ilana:

1. Yan `supportsAudio` nipasẹ `getResolvedModelCapabilities()`. Metadata
   olupese-ìkànsí ti o han gbangba ni o ṣẹgun, lẹhinna metadata awoṣe ti o wa, lẹhinna
   `modalities_input` ti a sin. Akojọ input ti a kede laisi `audio` jẹ `false`; ko si
   ẹri agbara ti o wa `null`. Mejeeji `false` ati `null` n mu
   ikọlu ti o ni aabo, nigba ti `true` n fo.
2. Yan `modalityBridgeAudio*` awọn eto ki o si fa awọn apakan audio ti o le
   pin lati gbogbo ifiranṣẹ nipasẹ `detectMediaParts()`
   oluyẹwo ti a pin. Awọn apẹrẹ waya ti a ṣe atilẹyin ni OpenAI `input_audio`, `audio_url`, ati
   `source.media_type: "audio/*"`. Audio ti a fi sinu ni a ṣe awari fun ikọlu ṣugbọn kii ṣe
   yọkuro nipasẹ ọna pin. Iṣẹ naa ni a fi opin si `modalityBridgeAudioMaxClips`;
   awọn apakan ti o tẹle wa ni a ko kan.
3. Bọwọ fun `provider/model` ti a ṣeto, tabi jẹ ki `selectAudioBridgeModel()` rin
   `AUDIO_TRANSCRIPTION_PROVIDERS` ni aṣẹ katalogu iduroṣinṣin ki o yan awoṣe akọkọ
   pẹlu iwe-ẹri olupese ti o ṣiṣẹ.
4. `callAudioTranscription()` yi audio base64/data-URI pada si multipart
   `file`, tabi gba `audio_url` latọna jijin nipasẹ aabo ti o wa fun gbogbo eniyan pẹlu DNS pinning ati opin 25 MB. O si POSTs faili naa ati awoṣe ti a yan si
   `/v1/audio/transcriptions` ikọlu ti agbegbe, ti a jẹrisi pẹlu
   `resolveSelfLoopBearer()`. Ọna ikọlu ti o wa n ṣe iwadi iwe-ẹri deede, itọju akoko / opin-iyara, ati firanṣẹ olupese.
5. Awọn ipe ti o ni aṣeyọri n rọpo awọn apakan wọn pẹlu `[Audio N]: <transcript>`. Awọn ipe
   n ṣiṣẹ pẹlu `Promise.allSettled`: ikuna kọọkan n pa apakan audio atilẹba yẹn (#4012 contract). Ti gbogbo ipe ba kuna ati ibi-afẹde ti fihan
   `supportsAudio === false`, awọn apakan di
   `[Audio N]: (unavailable — no STT provider connected)` (#8430 contract). Fun
   ibi-afẹde ti a ko mọ (`null`), abajade ikuna gbogbo wa ni a ko kan. Ibi-afẹde ti a fihan
   ti ọrọ nikan pẹlu ko si iwe-ẹri STT ti o le lo gba stub ti o han gbangba kanna
   laisi ṣiṣe ipe nẹtiwọọki.

Awọn akọsilẹ ti o ni aṣeyọri n lo Modality Bridge LRU/TTL cache ti o wa ni ilana. Bọtini naa n darapọ
iṣeduro audio, aami iṣẹ `audio-transcription` ti o wa ni iduroṣinṣin, ati awoṣe STT ti a yan; awọn ikuna ko ni a fi pamọ. Awọn igbiyanju audio n ṣe imudojuiwọn
`bridged`, `cacheHits`, `failures`, ati `lastUsedAt` awọn kaunti.
Awọn idahun ti a yipada n gbe
`x-omniroute-modality-bridge: audio->text;model=<sttModel>;parts=<n>`; awọn ibeere ti a ko kan
ko gba apakan Audio Bridge.

Awọn eto akoko wa ni atilẹyin DB ati Zod-validated:

| Bọtini                        | Aiyipada | Iwọn             |
| ----------------------------- | -------- | ---------------- |
| `modalityBridgeAudioEnabled`  | `true`   | —                |
| `modalityBridgeAudioModel`    | `""`     | Auto tabi STT ID |
| `modalityBridgeAudioTimeout`  | `60000`  | 1000–300000      |
| `modalityBridgeAudioMaxClips` | `3`      | 1–10             |

Ibi ipamọ ti a pin wa ni iṣakoso nipasẹ `modalityBridgeCacheEnabled`,
`modalityBridgeCacheTtlMinutes`, ati `modalityBridgeCacheMaxEntries`.

### Video Bridge (`videoBridge.ts`, `videoBridgePipeline.ts`)

N gba awọn apakan fidio ipele-giga ni Chat Completions `messages` ati Awọn Idahun
API `input` ṣaaju ki a pe ibi-afẹde ti ko ni atilẹyin fidio abinibi ti a mọ.
Awọn apẹrẹ ti a ṣe atilẹyin ni `input_video`, `video_url`, `video_source`, HTTPS URLs,
ati `data:video/*;base64,...` data URIs. Awọn orukọ faili ti o rọrun ni ọrọ ko ni
ṣe itọju gẹgẹbi fidio.

`VideoBridgeGuardrail.preCall` (`videoBridge.ts`) ni iṣakoso ibeere,
ayẹwo agbara/ilana, ikojọpọ fun ibeere kọọkan, ati ẹru idahun.
Iṣẹ fidio kọọkan — acquisition, ibi ipamọ abajade gbogbo, apejuwe aami
itẹsiwaju (ti o dapọ eyikeyi akọsilẹ ohun ti a sọ nipasẹ oluranlowo), ati awọn
iṣiro/ibajẹ/clean-up fun igbiyanju kọọkan — ti wa ni pamọ lẹhin `processVideoPart` ni
`videoBridgePipeline.ts`, ti a pe lẹẹkan fun apakan fidio kọọkan ninu
loop `preCall`. Modulu yẹn tun ṣe alaye awọn aala ibudo pato `VideoMediaBrokerPort`
(ni gbigba awọn byte ati yọ awọn fireemu ti a sampled), `VideoAudioTranscriptionPort`
(dapọ akọsilẹ ohun ti a sọ nipasẹ oluranlowo pẹlu awọn akọsilẹ ti a sampled), ati
`VideoDrilldownPort` (irisi ibi ipamọ atijọ). STT iṣelọpọ ati idaduro fireemu
ni a ṣe akopọ ni ayika ibudo ti n ṣapejuwe nipasẹ `createVideoSttAdapter` ati
`createVideoDrilldownAdapter`; eyi ti o kẹhin nlo igbesi aye opaque-handle ti a pin.

Ọna ibeere ti gbogbo eniyan `/v1` ko gba tabi pe subprocess kan. Awọn fidio latọna
ni a gba silẹ labẹ ibamu 50 MiB; awọn fidio inline base64 ni a ni
ibamu 36 MiB ti a ti yọ fun fidio kọọkan ki awoṣe/messages/envelope framing
le wa ni inu opin gbigba ibeere JSON ti gbogbo eniyan ti 50 MiB. Iwọn inline
ati awọn iṣiro iwọn ti a ti yọ ni a ṣayẹwo ṣaaju pinpin. HTTPS ni
a nilo lori URL latọna akọkọ ati gbogbo atunṣe, lilo aabo ti o wa
ti gbogbo eniyan nikan pẹlu DNS pinning. Awọn byte lẹhinna kọja aala broker
`POST /api/modality-bridge/video/extract` inu. Ọna yẹn jẹ
`LOCAL_ONLY` ati `SPAWN_CAPABLE`, gba nikan ibeere ti a fọwọsi fun
iṣẹ-ṣiṣe kọọkan, ti a gbẹkẹle-loopback, ati ko gba URL, ọna faili, executable,
tabi atokọ awọn ariyanjiyan. Iwọn ara API ati olutọju ti o n ka ara
ni ominira n ṣe imuse ibamu 50 MiB fun input broker. Ibi ipamọ rẹ ti o ni
ibamu n ṣiṣẹ ni extraction kan ni akoko kan, gba iṣẹ mẹrin ti o n duro de,
ati pe o ni ibamu input ti o n duro de ni 100 MiB.

Ninu broker, `ffprobe` ka faili agbegbe ikọkọ; atokọ fọọmu ti a ṣeto
ko gba awọn fọọmu akojọ orin ati manifest. Fun awọn apoti MOV-famili ti a gba,
awọn itọkasi data MOV ita wa ni pipade nipasẹ aiyipada, ati
aṣẹ ti a ṣeto ko ni yan wọn. Mejeeji `ffprobe` ati `ffmpeg` lo
atokọ fọọmu ti o da lori `file` nikan, okun kan, awọn akojọpọ ariyanjiyan ti a ṣeto, ko si shell,
ati awọn executable ti a yan lati `PATH`. Awọn ṣiṣan aworan ti a so mọ ko
ni awọn oludije ti o le ṣe. Gbogbo awọn ṣiṣan ti o le ṣe gbọdọ ni itẹlọrun awọn
ibamu, ati ṣiṣan aiyipada ti a ṣalaye ni a fẹran ṣaaju ki o to
iyipada ti o kere julọ ti a pinnu. Awọn fidio ni a ni opin si 600 iṣẹju-aaya, 8,192 pixels fun iwọn, ati
33,554,432 awọn pixel orisun. FFmpeg n sampled 1–16 awọn fireemu JPEG aarin, n dinku
ipa gigun si o pọju 1,024 pixels laisi imudara awọn input ti o kere, ati
ko gba URL. Sampling jẹ `uniform` nipasẹ aiyipada. Awọn ilana
`scene_aware` ti o wa ni aṣayan ati `segment_aware` ti idanwo ṣe iṣẹ FFmpeg
kan ti o ni idasilẹ lori ṣiṣan agbegbe ti a ti fọwọsi tẹlẹ, yan awọn
akoko `showinfo` ti a fi idi mulẹ, ati pada si awọn aarin ti o ni idasilẹ
ni pato ni ikuna oluyẹwo, akoko ti o pari, abajade ti ko tọ, tabi
seti oludije ofo. Ipo segment-aware n pin awọn ayẹwo aarin ni ibamu si
awọn akoko ṣiṣan ti a ti fọwọsi; ẹri segment-aware ati ihuwasi
iyipada ni a ṣe alaye ni isalẹ. Iwọn 16-frame ti o lagbara ni
lo lẹhin yiyan ni gbogbo ilana. Nigbati ibeere ti o ni imọlara ni
kan iye fireemu kan, o nlo aarin ti o ni ibamu ti fidio kikun ti n ṣiṣẹ tabi
window ifojusi ati ki o ṣe iroyin `policyEffective: uniform`: fireemu
aṣayan kan ko le pa awọn ipari akoko mejeeji. Oluranlowo le funni ni
window ifojusi ti o ni opin (`start`/`end` iṣẹju-aaya); awọn ibamu ni a
fi si iwọn media, awọn window ti a yipada tabi ti ko ni opin ni a kọ, ati gbogbo awọn ilana
sampling ni a ṣe nikan ni inu akoko ti a ti ni imudara. Iwọn ti o ṣẹda
ni a fi kun si metadata sampling ati ni prefix apejuwe ti ko ni igbẹkẹle
ki awọn awoṣe ti o wa ni isalẹ le ṣe iyatọ apakan ifojusi kan lati
akoko kikun.

Fojusi akọsilẹ ti o ni itumọ jẹ eto kan ti o yatọ, ti a ṣalaye. Ipo
itan `full` n pa aami fireemu ti o wa tẹlẹ mọ ati ko si
fi ọrọ ibeere ranṣẹ si awoṣe akọsilẹ. Ni ipo `focused`, bridge naa ka
nikan ọrọ ti o kẹhin ti ko ni ofo ti a kọ nipasẹ olumulo `text`/`input_text`
lati inu apoti Chat tabi Awọn Idahun kanna, n ṣe imudara si NFC, n dinku awọn
characters iṣakoso ati aaye, ati pe o ni ibamu si 500 Unicode code points. Abajade ofo
n pada si aami `full` gangan. Iṣeduro ti o wulo ni a ṣe ni JSON
ni bulọọki ti a yà fun olumulo ti ko ni igbẹkẹle ati pe o le nikan
fi awọn alaye ti a le rii; ko le kọja ikilọ ti o yapa lodi si
tite awọn ilana ti o han tabi ti a gbọ ni media. Fojusi ọrọ ko
ni fa `start`/`end` tabi yi pada
sampler akoko.

#### FU-07 ẹri apakan ilana

`segment_aware` nlo ọkan pre-analysis ti a fi opin si lori ṣiṣan fidio agbegbe ti a ti jẹrisi tẹlẹ. Ẹwọn àlẹmọ ti a ti ṣeto akọkọ n ṣe iwọn si ni o pọju 320 pixels ni iwọn, ṣe awari awọn ayipada oju-aye ati awọn akoko ti a da duro, lẹhinna n ṣe ayẹwo ni 1 fireemu fun iṣẹju kan fun blur, luma apapọ, ati alaye aaye/akoko. Ipasẹ naa ni opin si 600 awọn ayẹwo ilana, ọkan FFmpeg/filter thread, ilana `file`-nìkan ati awọn akojọ aṣayan apoti, a 1 MiB ilana-iyọkuro, ati ni o pọju 30 iṣẹju laarin akoko pinpin/akoko ipari broker. Ko gba aṣẹ, àlẹmọ, ọna, tabi URL lati inu ibeere.

Awọn iye ilana jẹ ẹri ayẹwo ti o ni idasilẹ, kii ṣe oye fidio ti o ni itumọ. Wọn ko ni imọran awọn koko-ọrọ, awọn iṣe, awọn akọle, ọrọ, tabi ifẹ olumulo. Awọn aala oju-aye ati idaduro ṣe agbekalẹ awọn apakan; ibiti idaduro, blur, ifihan, alaye aaye, ati ayipada akoko nikan ni ipa lori bi a ṣe pin inawo fireemu 1–16 ti o wa. Apakan ti o ti da duro patapata ni a fi opin si fireemu kan, nigba ti awọn apakan ti ko ni idaduro n ja fun inawo to ku. Nigbati awọn aala ba ju awọn fireemu lọ, a tọju ibiti akoko deede ki awọn gige kutukutu ti o yara ko le pa apakan ti o pẹ. Awọn aala oju-aye laarin ipinnu itupalẹ 1-aaya ti a da duro ni a dapọ.

Awọn àlẹmọ ti o padanu, ẹri ti ko ni apẹrẹ/tabi ofo, aṣiṣe olutọpa, tabi akoko idaduro pre-analysis ti a fi opin si kuna lati ṣii si eto aarin deede. Aṣẹ ti o pe tabi akoko ipari broker ko kuna lati ṣii: o pa subprocess ti nlọ lọwọ, dena ikojọpọ fireemu nigbamii, ati pe igi aladani igba diẹ ni a yọ ni `finally`.

`scripts/perf/video-bridge-fu07-eval.ts` n ṣe agbejade awọn ohun elo FFmpeg gidi ti o ni idasilẹ fun awọn ifipamọ ipe akọle lẹhin-dedup, pinpin inawo gbigbe ti o nipọn, ẹri blur/ifihan/SI-TI, awọn gige yara pẹlu ejika gigun, ati awọn aṣiṣe ti o fa idaduro. O n ṣe igbasilẹ akoko ogiri pre-analysis ati, nibiti `/usr/bin/time` ba wa, CPU ọmọ ati RSS to ga. Awọn ayẹwo didara rẹ jẹ awọn oracle ilana nikan. Didara awoṣe akọle gidi wa ni `HOLD` nitori pe ẹrọ yii ko ni opin ti a fọwọsi tabi idajọ ti a da duro. Awọn ifipamọ owo tun wa ni `HOLD` ayafi ti `--caption-cost-per-call-usd` ba pese iṣiro rere ti o han kedere fun ipe kọọkan; iwe afọwọkọ naa ko ṣẹda boya abajade.

Gbogbo fireemu ni a fi opin si 4 MiB, gbogbo awọn fireemu raw papọ si 23 MiB, ati idahun broker ti a ṣe atokọ si 32 MiB. A yọ itọsọna aladani igba diẹ ni `finally`. OmniRoute ko dapọ FFmpeg ati pe ko gba ọna ṣiṣe aṣa. Ṣaaju ki o to ṣe akọle, afara naa n lo ipari wiwo ti o ni idasilẹ: JPEG kọọkan ni a dinku si ibudo grayscale 16×16 ati pe a n ṣe afiwe nikan pẹlu fireemu ikẹhin ti a tọju. Fun inawo akọle ti a beere ti o ga ju fireemu kan lọ, ikojọpọ n pese adagun oludije ti o ni opin si igba meji ti inawo yẹn ati ko si ju fireemu 16 lọ. A lo idiwọn ti a beere nikan lẹhin deduplication, pẹlu awọn oludije ti a yan akọkọ ati ikẹhin ti a tọju lakoko ikẹkọ ikẹhin nigbati inawo ba kere ju meji. Ilana ti a ṣe ẹya `grayscale-16x16-mean-cells-v2` n lo ti o tobi julọ ti delta luma apapọ ati ipin ti awọn iboju kekere ti delta ti a ṣe deede jẹ o kere ju 0.05. Iwọn idapọ jẹ 0.04, ti a yan fun iṣedede dipo ki o han gẹgẹbi eto akoko ṣiṣe. Ibi ifihan keji yii ti o ni iyatọ giga n tọju awọn iyipo kekere ati awọn ayipada ọrọ ti o han ti afiwe apapọ nikan le pa. Awọn aṣiṣe afiwe tabi olutọpa kuna lati ṣii ati tọju ibiti. Metadata jade ya awọn oludije ti a fa, awọn fireemu ti a lo ni aṣeyọri, ati awọn ẹda wiwo ti a ju silẹ.

Apakan fidio ti a samisi ni kedere le beere iwe asopọ ti a samisi akoko. Afara naa n kọ grid JPEG ti o ni awọn ọwọn 4, 16-fireemu ni o pọju. Gbogbo sẹẹli 512-pixel n fa akoko orisun rẹ sinu ibamu ti o ni iyatọ giga ni isalẹ, nigba ti awọn akoko kanna wa ninu metadata ọrọ fun asopọ ati ayẹwo ni isalẹ. JPEG pipe wa ni opin si 32 MiB. Ti `sharp` ko ba le ṣe itumọ tabi ṣe akojọpọ grid, afara naa pada si awọn fireemu JPEG kọọkan; aṣẹ alabara kan ṣi n tan kaakiri nipasẹ iṣẹ iwe.

Ẹri igbega jẹ ni pataki yato si iṣiro akopọ sintetiki microbenchmark. `scripts/perf/video-bridge-contact-sheet-eval.ts` n ṣalaye ẹya-ara A/B ti a ṣe ẹya fun awọn awoṣe iran ti o ni ibamu pẹlu OpenAI gidi. O n ṣe iwọn awọn ami ti a royin nipasẹ olupese, idaduro ogiri ipari-si-ipari (pẹlu akopọ iwe), nọmba ipe awoṣe, ati idaduro otitọ ti a ṣe alaye. Awọn idahun awoṣe raw ko kọ sinu ijabọ; awọn digests SHA-256 nikan ati awọn ID otitọ ti a baamu ni a tọju. Ẹrọ naa ko ṣe ipe nẹtiwọki tabi awoṣe ti a san ayafi ti `--execute-real` ba wa ni gbigbe ati `--model`, `OMNIROUTE_BASE_URL`, ati `OMNIROUTE_API_KEY` ti wa ni iṣeto. Lai si ṣiṣe gidi yẹn, ipinnu ti o le ka ẹrọ rẹ wa ni `HOLD`; awọn wiwọn iwuwo sintetiki/ipe nikan ko jẹ ẹri igbega.

`scripts/perf/video-bridge-promotion-eval.ts` ti o yato si n jẹ awọn akiyesi FU-07 tabi FU-09. Ní àwọn ọ̀nà àtúnṣe wọ̀nyí, àwọn ìkìlọ̀ olùpejọ tó wúlò di àwọn apá `text`/`input_text` tó ní ìtẹ́wọ́gbà dipo àwọn ààyè olùpèsè tí kò jẹ́ àtúnṣe. Mejeji àwọn orin tí a fi ránṣẹ́ àti àwọn ìkìlọ̀ `client` jẹ́ àfihàn tí a kò gbàgbọ́, pẹ̀lú ìkìlọ̀ kedere pé fíìmù náà kò tíì ṣe àpejuwe àti pé a kò tíì jẹ́risi àwọn àmì àkókò lòdì sí àwọn média. Àwọn ìkìlọ̀ 256/64-KiB lapapọ àti fún ọkọ̀ọ̀kan wà fún àwọn orin méjèèjì; àwọn àmì àkókò gbọ́dọ̀ ba ààlà 600-sekondi ti alágbàá ṣe àti eyikeyi àyè àfihàn tí a fi ránṣẹ́. Àwọn orin tí kò wúlò ni a yọkúrò, a kò fi ránṣẹ́ gẹ́gẹ́ bí ìkìlọ̀ àìmọ̀; ìkìlọ̀ tó wúlò lè ṣi wúlò ayafi tí àkúnya wọn pọ̀ ju. Àwọn ààyè àìmọ̀/àìkúnya kò fi ìkìlọ̀ kankan kún. Kò sí ìkànsí média tàbí ìtúpalẹ̀ tí a fi kún nipasẹ àtúnṣe yìí. Àwọn ààyè ìtẹ̀sí ìtúpalẹ̀ ni a yọkúrò láti inú olùkópa fíìmù àtúnṣe àti àwọn ohun `video_url`/`source` rẹ. Àtúnṣe àtẹ̀jáde OpenAI jẹ́ kedere; àwọn olùkópa fíìmù àìmọ̀ ṣi wà nípò àti àwọn ibi àfihàn tí a mọ̀ pé kò ní média ní ààlà ààbò. Àwọn ojúṣe àtúnṣe tó dá lórí àtẹ̀jáde ń daabobo ìkìlọ̀ àtẹ̀jáde, nígbà tí ìbéèrè olùpejọ àtúnṣe kò yí padà.

Àwọn ẹ̀dá míì tí a pa mọ́ lo àfihàn ìbéèrè tó wà. Àwọn àwòrán ìbéèrè olùpèsè, ìbéèrè tó wà nínú iranti, àti ìkànsí ìbéèrè tí a kọ́kọ́ kọ́ ni a yí padà sí àwọn ààyè ìtúpalẹ̀ nínú àwọn apá fíìmù; àwọn ìkìlọ̀ àkópọ̀ tí a ṣe àtúnṣe nipasẹ àwọn ìpẹ̀yà pipeline àti ìkànsí àkópọ̀ ni a yọkúrò ní ibi ìbéèrè tí a pa mọ́. Àwọn àmì `video_content_removed` tó pa mọ́ ń jẹ́ kí ìtẹ̀sí `previous_response_id` kọ́kọ́ parí dipo kí o tún ṣe ìkìlọ̀ tí a yọkúrò. Tí ìbéèrè tó wà bá padanu ìkìlọ̀ àtúnṣe rẹ̀ ṣáájú ìkànsí, tàbí pé ọkan nínú àwọn ìkìlọ̀ fíìmù mẹta kò ba àfihàn lẹ́yìn ìyípadà ìbéèrè, a yọkúrò ní gbogbo ara ìbéèrè dipo kí a pa mọ́ ìtúpalẹ̀ tí a yọkúrò.

Fún ìbéèrè tó wà, ìdáhùn àpẹẹrẹ lè tọ́ka sí apá kankan ti ìtúpalẹ̀ láìsí ààlà ìkìlọ̀ tó dá lórí. Àwọn `responseBody` ìkànsí rẹ̀ ni a yí padà sí àmì yọkúrò; àwòrán pipeline tó ní ìtẹ́lọ́run (tó lè ní àwọn ara upstream/client àti àwọn apá ṣiṣan) kò ní pa mọ́. Àwọn àkópọ̀ àkópọ̀, idempotency, àti reasoning-replay bypass àwọn kika àti kọ́ fún ìbéèrè yẹn. Ìbéèrè olùpèsè àti ìdáhùn tó wà fún olùpèsè kò yí padà. Àwọn bytes keepalive tí a kọ́kọ́ yọkúrò láti inú àpò àkópọ̀ nígbà tí a yọkúrò ní àwòrán àtẹ̀jáde. Kiro's malformed EventStream ìkìlọ̀ ń jẹ́ kí a mọ̀ pé iye byte payload ni a rò, kò sí akoonu rẹ̀ tàbí aṣiṣe raw JSON parser.

Eyi kò sọ pé gbogbo ìṣàkóso olùpèsè/plugin tí kò ní ìbáṣepọ̀ ti wà nínú àyẹ̀wò; àtẹ̀jáde àtúnṣe tó gbooro ni a tọ́pa nínú #11658.

Kí ìbéèrè olùpèsè kan tó wà, ó gbọ́dọ̀ fa ID yẹn láti ọdọ tenant tó ti jẹ́risi àti kò gbọ́dọ̀ fi iye tí olùpèsè yan ránṣẹ́. Àwọn bọtini cache ń so olùpèsè yẹn pọ̀ mọ́ ID ìpẹ̀yà àti ID fíìmù, ń pa bọtini wọn tó jẹ́ SHA-256, àti ń ṣe àfihàn kika àti yọkúrò sí olùpèsè yẹn. lai faagun ilana orisun CORS. Awọn ọwọ tuntun lo `v1.<32-byte random base64url
token>`, ati pe ibi ipamọ naa n pa awọn SHA-256 hashes wọn nikan. Oluka/oluka akọsori naa tun gba awọn
token 64-hex atijọ. Onibara ti a fọwọsi jẹ
`GET /api/v1/video-bridge/drilldown?handle=...`, ti a ti pa nipasẹ
`modalityBridgeVideoDrilldownRemoteEnabled=true`. Iṣeduro ti a fi idi mulẹ ti ko tọ
n yọkuro iraye paapaa nigbati `OMNIROUTE_VIDEO_BRIDGE_DRILLDOWN_REMOTE_ENABLED` env
fallback ti wa ni mu. Iṣeduro iṣelọpọ ni ibamu pẹlu
`OMNIROUTE_VIDEO_BRIDGE_DRILLDOWN_ENABLED` fallback. Mejeeji awọn fallback jẹ aiyipada.

Onibara naa n gba ownership lati ọdọ bọtini ti a fọwọsi, lo ilana bọtini, ati
da 404 kanna pada fun awọn ọwọ ti ko mọ, ti o ti parẹ ati ọwọ bọtini miiran. O gba
`variant=preview|standard|detail` (ipin JPEG ti o pọ julọ 320/640/1280, ko si ni iwọn),
`limit=1..8` (tabi alias atijọ `frames`, ko si ni mejeeji), `page` ti o da lori odo, ati
`start`/`end` awọn aaya idojukọ ti o jẹ aṣayan. Awọn
bọtini ibeere ti o tun ṣe ati awọn ferese idojukọ ti a yi pada ni a kọ. Kọọkan
variant ti a da pada ni hash ti akoonu gangan rẹ ati metadata ipinnu gangan, ti a so pọ
si orisun ti a pa. Awọn variants ni a gba ni kika dipo ki o wa ni fipamọ gẹgẹbi awọn ẹda ti a pa. JSON
idahun, pẹlu Base64/envelope, ni a fi opin si 32 MiB; oju-iwe ti o tobi ju ni a pada
413 ati pe alabara gbọdọ beere fun awọn fireemu diẹ. Awọn kika n ṣayẹwo ipinnu ni ayika
kọọkan iwọn ati tun ṣayẹwo iwulo ọwọ ṣaaju ki o to da pada. `DELETE` nipasẹ oniwun jẹ idempotent;
piparẹ tabi TTL parẹ tu orisun ti a pa ati iṣiro lilo.

Ibi ipamọ ti a pin jẹ agbegbe ilana: awọn ọwọ parẹ nigbati a tun bẹrẹ ati pe ko le gbe
lati awọn ilana OmniRoute ti ominira. Awọn iṣiro iṣakoso n fi han ipamọ ti o munadoko/
ilana latọna ati akojọpọ awọn akọsilẹ ti a pa/bytes nikan, ko si awọn media, awọn itọkasi,
IDs pataki tabi awọn ọwọ. Iboju eto Video n fihan awọn iye wọnyẹn ati pe o le pa
mejeeji awọn iyipada ifọwọsi. Iwe aṣẹ imuse yii kii ṣe ẹri ifilọlẹ laaye tabi
ipolowo; gbigba awoṣe gidi ni a tọpinpin ni iyasọtọ.

Awọn fireemu ni a fi akọsilẹ si ni aṣẹ pẹlu awoṣe Video ti a ṣeto. Iboju
Video ti ko ni nkan gba eto Vision; ti mejeeji ba ṣofo, olutọpa auto Vision
yan awoṣe ti o ni agbara iran ti o munadoko. Awọn akọsilẹ ti o ṣaṣeyọri
rọpo apakan atilẹba pẹlu `[Video description:` prefix ti o wa ni iduroṣinṣin ti o tun
samisi ọrọ naa gẹgẹbi akiyesi ti a ko ni igbẹkẹle ti o ni ipilẹ media ati sọ fun awọn awoṣe
ti o wa ni isalẹ lati ma tẹle awọn ilana ti a rii ninu media. Awọn bọtini kaṣe akọsilẹ
ni awọn byte JPEG, iwifunni, akoko, ati awoṣe ti o munadoko; awọn akọsilẹ ti o ṣaṣeyọri nikan ni a kaṣe. Awọn akọsilẹ kaṣe n pa awoṣe olutayo ti o ṣaṣeyọri,
pẹlu awoṣe fallback; iboju naa n ṣe iroyin `mixed` nigbati awọn fireemu oriṣiriṣi
ni a ṣe nipasẹ awọn awoṣe oriṣiriṣi. Ipa kaṣe kan tun lo idanimọ olutayo yẹn
dipo ki o tun ṣe akọle rẹ gẹgẹbi eto itọsọna ti a beere. Kaṣe abajade-gbogbo-video
ni a fi bọtini si gbogbo input ti o yipada jade — iwifunni, awoṣe ti o munadoko, ilana ayẹwo, nọmba fireemu, ipo itupalẹ itumọ, SHA-256
fingprint ti itọkasi idojukọ ti a ṣe deede, ferese idojukọ, `transcript`,
`audioTranscript`, ati asia iwe olubasọrọ — nitorinaa yiyipada eyikeyi ninu awọn
ipin wọnyẹn jẹ kaṣe ti o padanu, ko si ni tun lo ti o ti kọja. Ẹya ilana dedup
ti o han, ipele, ati nọmba fireemu oludije ti a fi opin si tun jẹ kedere ninu
bọtini kaṣe abajade ati metadata; iyipada ilana kan nitorinaa ko le tun lo apejuwe-gbogbo-video ti o ti kọja. Metadata kaṣe abajade v4 n pa ipo ati
fingprint, ko si ni iṣẹ-ṣiṣe olumulo aise. Metadata guardrail n ṣe iroyin mejeeji
awọn ipo itupalẹ ti a beere ati ti o munadoko; ipo `focused` ti a beere laisi
ọrọ olumulo ti o wulo ni a ṣe iroyin gẹgẹbi `full` ni imunadoko.

Guardrail naa n fa gbogbo apakan fidio ti a ṣe atilẹyin ṣugbọn ko ṣe apejuwe ju
`modalityBridgeVideoMaxVideos` lọ. Fun ibi-afẹde ti a fihan pe o ni
`supportsVideo === false`, awọn fidio ti o kuna ati ti o ju iwọn lọ di awọn ami ọrọ
ailewu ti o han ki fidio aise ko ye. Nigbati agbara ko mọ, awọn apakan wọnyẹn
n pa ọkọ fidio wọn; eyikeyi transcript fallback tẹle iyipada ọrọ ti a fi opin si loke. Awọn ibi-afẹde pẹlu `supportsVideo === true` n yago fun iboju naa.
Ibi ibeere alabara ti a dawọ duro n tan kaakiri nipasẹ igbasilẹ, akojọ broker,
subprocesses, ati awọn ipe akọsilẹ; awọn idaduro da duro laarin awọn fidio ati pe ko si
ni kuna si media aise.

Awọn eto akoko jẹ atilẹyin DB ati Zod-validated:

| Bọtini                              | Aiyipada    | Iwọn / ihuwasi                                                                                        |
| ----------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------- |
| `modalityBridgeVideoEnabled`        | `false`     | Aiyipada akoko, opt-in                                                                                |
| `modalityBridgeVideoAnalysisMode`   | `"full"`    | `full` pa awọn akọsilẹ gbogbogbo; `focused` lo ti a fi opin si, ti ko ni igbẹkẹle ti olumulo to kẹhin |
| `modalityBridgeVideoModel`          | `""`        | Gba awoṣe Vision Bridge                                                                               |
| `modalityBridgeVideoFrameCount`     | `8`         | 1–16                                                                                                  |
| `modalityBridgeVideoSamplingPolicy` | `"uniform"` | `uniform`, `scene_aware`, tabi `segment_aware` ti o ni ipin; ikuna olutọpa pada si `uniform`          |
| `modalityBridgeVideoMaxVideos`      | `1`         | 1–4                                                                                                   |
| `modalityBridgeVideoTimeout`        | `120000`    | 1000–120000 ms                                                                                        |

Legacy persisted Video timeout values above 120 seconds are clamped to the
broker deadline; new settings writes above that limit are rejected.
`GET /api/modality-bridge/video/runtime` requires trusted stamped loopback
locality before authentication or runtime probing, then requires management
auth. It returns only `available`, sanitized FFmpeg/ffprobe versions, and a fixed
reason when the runtime is unavailable. The internal extraction endpoint is not
a public upload API: queue saturation returns `503` plus `Retry-After`, a caller
disconnect returns `499`, and the fixed broker deadline returns `504`. Converted responses add
`video->text;model=<visionModel>;parts=<videos>` to the central
`x-omniroute-modality-bridge` header without removing Vision or Audio segments.

### PII Masker (`piiMasker.ts`)

Nṣiṣẹ lori **mejeeji** ipele.

- **`preCall`** n ṣe ẹda ti payload, n rin `system`, `messages`, `input`, ati
  `prompt` (pẹlu awọn nkan okun ti o rọrun), ati lo `processPII()` (lati
  `@/shared/utils/inputSanitizer`) si awọn aaye okun `content`/`text`. Nigbati
  `PII_REDACTION_ENABLED=true`, PII ti a ri ni a pa ni outbound
  payload. Eyi jẹ ominira ti `INPUT_SANITIZER_MODE` (eyi ti o kan iṣakoso
  ilana ifọwọsi prompt). Nigbati a ba pa, awọn igbasilẹ ipe ṣe iṣiro awọn
  iroyin ti a ri laisi atunṣe akoonu.
- **`postCall`** n ṣe ẹda jinlẹ ti idahun, n ṣiṣẹ `sanitizePIIResponse()` ati
  masker apẹrẹ Responses-API (`maskResponsesOutput` — bo
  `output_text` ati `output[].content[].text`). Ti eyikeyi pa ba waye, idahun
  ti a yipada rọpo atilẹba.

Iboju ko da a duro; o kan ṣe akọsilẹ (`meta.detections`,
`meta.redacted`) tabi tun kọ.

### Prompt Injection (`promptInjection.ts`)

N ṣe awari awọn ilana alatako ninu akoonu ti olumulo pese ati fi agbara mu
ilana ti a ti ṣeto. Iwa naa ni a fa nipasẹ awọn oniyipada ayika ati awọn aṣayan
constructor:

| Eto         | Env var                                                                                               | Aiyipada | Ipa                                                                                                                                                                       |
| ----------- | ----------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ti muu ṣiṣẹ | `INPUT_SANITIZER_ENABLED`                                                                             | `true`   | Nigbati `false`, iboju n ṣe kukuru.                                                                                                                                       |
| Ipo         | `INJECTION_GUARD_MODE` / `INPUT_SANITIZER_MODE`                                                       | `warn`   | Ilana ifọwọsi: `block`, `warn`, tabi `log`. (`redact` ni a gba fun ibamu pada ṣugbọn ko **yọ** ọrọ ifọwọsi; ibeere PII tunṣe ni a ṣakoso nipasẹ `PII_REDACTION_ENABLED`.) |
| Iwọn idiwọ  | `blockThreshold` aṣayan / `INPUT_SANITIZER_BLOCK_THRESHOLD` (alias `INJECTION_GUARD_BLOCK_THRESHOLD`) | `high`   | Iwọn ti o kere julọ ti a nilo lati da duro. Medium jẹ akiyesi nikan ni aiyipada.                                                                                          |

**Ipo precedence** (`getMode`): ipe `options.mode` →
`INJECTION_GUARD_MODE` **DB feature-flag override** (Dashboard → Settings →
Feature Flags) → `INJECTION_GUARD_MODE` env → `INPUT_SANITIZER_MODE` env →
`warn`. Iboju ti dashboard n gba agbara lori awọn oniyipada ayika, nitorinaa UI Feature
Flags n ṣakoso iboju ti n ṣiṣẹ laaye (ko si atunbere). Ika DB jẹ aabo-ikuna:
ti o ba ni aṣiṣe, iboju naa pada si iwa ti o da lori ayika, ati nigbati ko si
iyipada ti a ṣeto, iwa naa jẹ idanimọ si ipinnu nikan ti ayika.

Awọn orisun awari:

1. `sanitizeRequest()` lati `@/shared/utils/inputSanitizer` (seti oluwari ti a pin
   ti a lo ni ibomiiran ninu pipeline).
2. `DEFAULT_GUARD_PATTERNS` ti a kọ sinu (ni lọwọlọwọ `system_override_inline` ati
   `markdown_system_block`, mejeeji `high` iwa).
3. `customPatterns` ti a fi silẹ nipasẹ awọn aṣayan constructor (okun, regex,
   tabi `{ name, pattern, severity }` awọn igbasilẹ).

Nigbati `mode === "block"` **ati** o kere ju awari kan ti pade iwọn
idena, `preCall` n pada `{ block: true, message: "Request rejected:
suspicious content detected" }`. Ni awọn ipo `warn`/`log`, iboju naa n ṣe igbasilẹ ṣugbọn
n gba ipe naa. Oluranlọwọ ti a pin `evaluatePromptInjection()` tun ti wa ni
ṣafihan fun awọn olupe ti o nilo lati ṣe ayẹwo awọn ifọrọranṣẹ laisi lilọ nipasẹ
iwe akọọlẹ.

**Scan bound (v3.8.20):** oluwari naa n ṣayẹwo **kọkọ 16 KB** ti
ọrọ ifọrọranṣẹ ti a darapọ — `MAX_INJECTION_SCAN_BYTES = 16 * 1024` (16 384 bytes) ni
`src/shared/utils/inputSanitizer.ts`. Mejeeji `detectInjection()` ati
`evaluatePromptInjection()` `slice(0, MAX_INJECTION_SCAN_BYTES)` ṣaaju ṣiṣe
iyika ilana. Awọn itọsọna ifọwọsi wa nitosi oke ti input, nitorinaa eyi
n ṣe idiwọ regex CPU/GC lori awọn payload ti o ni ọpọlọpọ awọn KB laisi dinku awari (cf.
#3932, #4041).

### Credential Masker (`credentialMasker.ts`)

Nṣiṣẹ lori **mejeeji** ipele, ikẹhin ninu pq aiyipada (aṣẹ `95`). N pa
awọn ilana API-key / secret-token ti a mọ daradara lati inu outbound payload (akoonu
ifiranṣẹ, awọn ariyanjiyan ipe irinṣẹ, awọn abajade irinṣẹ) **ati** idahun
olupese, nitorinaa a ko le fi ẹri kan ti a fi sinu ifọrọranṣẹ (tabi ti a sọ pada nipasẹ abajade irinṣẹ) si olupese ti o ga julọ tabi pada si alabara.

- **Opt-in nikan**, ilana kanna bi PII redaction (Iṣeduro Iṣeduro #20-adjacent):
  ti wa ni pipade ayafi ti `settings.credentialRedactionEnabled === true` **tabi**
  `CREDENTIAL_REDACTION_ENABLED=true`. Pẹlu rẹ pa, aabo naa jẹ aisi —
  ko ṣe idiwọ rara ati ko tun kọ.
- `redactCredentials()` n rin gbogbo ẹru/ìdáhùn igi (`walkValue()`,
  aabo-prototype-pollution, aabo-cycle nipasẹ `WeakSet`) ati rọpo awọn ibamu pẹlu
  a `[REDACTED:<type>]` aaye iduro, n ṣe ẹda nikan awọn ẹka ti o ti
  yipada gaan.
- `CREDENTIAL_PATTERNS` bo awọn bọtini olupese LLM (OpenAI, OpenAI-proj,
  Anthropic, Google, Hugging Face, Replicate), awọn tokini VCS/SaaS (GitHub, Slack,
  Linear, Notion, npm, Postman, Discord), awọn bọtini isanwo (Stripe, Square), awọn bọtini awọsanma (AWS access key, Twilio, SendGrid, Mailgun), awọn bọtini ikọkọ / JWTs,
  awọn okun asopọ ti o ni ẹri (`mongodb://user:pass@...`, ati bẹbẹ lọ), ati
  ilana `Authorization`/`x-api-key`/`api-key`/`apikey` ti o wọpọ. Awọn bọtini ti o ni apẹrẹ akọle (`authorization`, `x-api-key`, `api-key`,
  `apikey`) ni a ṣe idiwọ ni ọna ti a ṣe (iye nikan, ilana prefix bi
  `Bearer `/`Basic ` ti wa ni fipamọ) dipo nipasẹ regex ọrọ gbogbogbo.
- Aabo naa ko ṣe idiwọ rara; o kan tun kọ (`modifiedPayload` /
  `modifiedResponse`) ati ṣe akọsilẹ (`meta.credentialsRedacted`, `meta.count`).

Aabo idibajẹ: `tests/unit/credential-masker-guardrail.test.ts`.

## Àdéhùn Ìpìlẹ̀ (`base.ts`)

```typescript
class BaseGuardrail {
  enabled: boolean;
  name: string;
  priority: number;

  constructor(name: string, options?: { enabled?: boolean; priority?: number });

  async preCall(payload: unknown, context: GuardrailContext): Promise<GuardrailResult | void>;

  async postCall(response: unknown, context: GuardrailContext): Promise<GuardrailResult | void>;
}

interface GuardrailResult<TValue = unknown> {
  block?: boolean; // true máa ń dá pq náà dúró lẹ́sẹ̀kẹsẹ̀
  message?: string; // a máa ṣàfihàn rẹ̀ nígbà ìdènà
  meta?: Record<string, unknown> | null;
  modifiedPayload?: TValue; // preCall ló máa dá a padà láti tún ìbéèrè kọ
  modifiedResponse?: TValue; // postCall ló máa dá a padà láti tún ìdáhùn kọ
}

interface GuardrailContext {
  apiKeyInfo?: Record<string, unknown> | null;
  disabledGuardrails?: string[] | null;
  endpoint?: string | null;
  headers?: Headers | Record<string, unknown> | null;
  log?: GuardrailLog | Console | null;
  method?: string | null;
  model?: string | null;
  provider?: string | null;
  signal?: AbortSignal;
  sourceFormat?: string | null;
  stream?: boolean;
  targetFormat?: string | null;
}
```

Guardrail kan máa ń fi hàn pé “kò sí àyípadà” nípa dídá bóyá `void`, `{}`, tàbí
`{ block: false }` padà. Dídá `modifiedPayload`/`modifiedResponse` padà máa ń rọ́pò
iye tí ń ṣàn gba inú pq náà fún àwọn guardrail tó wà lẹ́yìn.
`signal?: AbortSignal` ń gbé ìgbésí-ayé olùpè wọ inú àwọn guardrail. Ìfagilé ìbéèrè jẹ́ ìyàsọ́tọ̀ fail-open tí a mọ̀ọ́mọ̀ ṣe: àwọn afárá mídíà máa ń dá iṣẹ́ dúró, wọ́n sì máa ń ṣe ìmótótó láì dá mídíà àìṣiṣẹ́ padà sí ibi-afẹ́ kan tí a mọ̀ pé kò ṣe àtìlẹ́yìn fún un.

## Ìforúkọsílẹ̀ (`registry.ts`)

Singleton `guardrailRegistry` ń pèsè:

- `register(guardrail)` — ń fi guardrail kan kún un (tàbí rọ́pò rẹ̀ nípa orúkọ tí a ti ṣe déédéé), ó sì
  tún wọn tò nípasẹ̀ `priority` láti kékeré sí ńlá.
- `clear()` / `list()` — àwọn irinṣẹ́ ìrànlọ́wọ́ ìṣàkóso.
- `runPreCallHooks(payload, context)` — ń yípo lórí àwọn guardrail tí ń ṣiṣẹ́, ó ń gbé
  payload gba inú `modifiedPayload`, ó sì máa ń dá dúró ní `block: true` àkọ́kọ́.
- `runPostCallHooks(response, context)` — ìṣàn kan náà ní ẹ̀gbẹ́ ìdáhùn.
- `resetGuardrailsForTests({ registerDefaults })` — ń pa ipò rẹ́, ó sì lè
  tún àwọn iye àìyípadà forúkọsílẹ̀ fún ìyàsọ́tọ̀ ìdánwò tó mọ́.

Àwọn olùṣiṣẹ́ méjèèjì máa ń dá `{ blocked, payload|response, results, guardrail?, message? }`
padà, níbi tí `results` ti jẹ́ àkójọpọ̀ àwọn àkọsílẹ̀ `GuardrailExecutionResult` tí ó ní
àwọn pápá `blocked`, `skipped`, `modified`, `error`, àti `meta` fún guardrail kọ̀ọ̀kan,
tí ó wúlò fún ìtọpasẹ̀.

### Ṣíṣàìṣiṣẹ́ Àwọn Guardrail Fún Ìbéèrè Kọ̀ọ̀kan

`resolveDisabledGuardrails({ apiKeyInfo, body, headers })` ń kó àkójọ àwọn orúkọ
guardrail tí kò ní àdàkọ jọ, èyí tí ó yẹ kí a fo fún ìbéèrè tó wà lọ́wọ́.
Àwọn orísun (gbogbo wọn jẹ́ àṣàyàn, gbogbo wọn ni a parapọ̀):

- `apiKeyInfo.disabledGuardrails`
- `disabledGuardrails` inú body ìbéèrè (ní ìpele òkè)
- `metadata.disabledGuardrails` inú body ìbéèrè
- Header `x-omniroute-disabled-guardrails` (tàbí ti àtijọ́
  `x-disabled-guardrails`)

Àwọn iye lè jẹ́ àkójọpọ̀ àwọn ọ̀rọ̀ tàbí ọ̀rọ̀ kan tí kọ́má pín sí ọ̀tọ̀ọ̀tọ̀; àwọn orúkọ ni a
máa ń ṣe déédéé sí lowercase kebab-case (`pii_masker` → `pii-masker`). Àbájáde náà
ni a máa ń fi ránṣẹ́ gba inú `context.disabledGuardrails` sí ibi ìforúkọsílẹ̀, èyí tí ó máa ń fo
àwọn guardrail tó bá mu (`skipped: true` nínú `results`).

## Ètò Ìṣiṣẹ́

Fún ìbéèrè kọ̀ọ̀kan tí ń kọjá láti inú `src/sse/handlers/chat.ts` àti
`open-sse/handlers/chatCore.ts`:

1. `resolveDisabledGuardrails(...)` ń kọ àtòkọ àwọn ohun tí a máa fo kọjá láti inú kọ́kọ́rọ́ API, ara ìbéèrè,
   àti àwọn àkọlé.
2. `guardrailRegistry.runPreCallHooks(body, ctx)` ń ṣiṣẹ́ àwọn guardrail ní ìtòlẹ́sẹẹsẹ
   ààyò láti kékeré sí ńlá:
   - Àwọn guardrail tí a ti pa ni a máa forúkọ sílẹ̀ gẹ́gẹ́ bí `skipped`.
   - `preCall` guardrail kọ̀ọ̀kan lè tún payload kọ nípasẹ̀ `modifiedPayload`.
   - `block: true` àkọ́kọ́ dá ẹ̀wọ̀n náà dúró lẹ́sẹ̀kẹsẹ̀, handler náà sì dá
     èsì ìkọ̀sílẹ̀ guardrail padà.
3. Payload náà (èyí tí ó ṣeé ṣe kí a ti tún kọ) ń lọ sínú combo routing àti
   ìfiránṣẹ́ sí upstream.
4. Lẹ́yìn tí a bá ti ṣàkójọ èsì náà, `guardrailRegistry.runPostCallHooks(...)`
   ń ṣiṣẹ́ ẹ̀wọ̀n kan náà lórí èsì náà. `block: true` níbí yóò sọ
   èsì upstream náà nù.

Àwọn guardrail tí ó ju àṣìṣe jáde ni a máa forúkọ sílẹ̀ pẹ̀lú `error: <message>`, a sì máa kọ wọ́n sínú log nípasẹ̀
`logger.warn`, ṣùgbọ́n ẹ̀wọ̀n náà yóò tẹ̀síwájú — ó jẹ́ àpẹrẹ fail-open.

## Ìṣètò

Àwọn àyípadà àyíká tí àwọn guardrail inú-ẹ̀rọ ń kà:

| Àyípadà                               | Ohun tí ó ń lò ó          | Ipa                                                                                         |
| ------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------- |
| `INPUT_SANITIZER_ENABLED`             | `prompt-injection`        | Ṣètò sí `false` láti pa ìṣàwárí rẹ́ pátápátá.                                                |
| `INPUT_SANITIZER_MODE`                | `prompt-injection`        | Ìlànà injection: `warn`, `block`, tàbí `log`. Iye àtijọ́ `redact` kì í tún ọ̀rọ̀ injection kọ. |
| `INJECTION_GUARD_MODE`                | `prompt-injection`        | Ipo fún injection guard; ó tún jẹ́ àsìá ẹ̀yà DB tí ó **borí** àwọn env vars (DB > ENV).       |
| `INPUT_SANITIZER_BLOCK_THRESHOLD`     | `prompt-injection`        | Ìwọ̀n ewu tó kéré jù tí `MODE=block` máa kọ̀: `high` (àiyípadà àkọ́kọ́), `medium`, tàbí `low`.  |
| `INJECTION_GUARD_BLOCK_THRESHOLD`     | `prompt-injection`        | Orúkọ àpèjúwe àtijọ́ fún `INPUT_SANITIZER_BLOCK_THRESHOLD`.                                  |
| `PII_REDACTION_ENABLED`               | `pii-masker`              | Nígbà tí ó jẹ́ `true`, PII inú ìbéèrè ni a máa fi bo (láìka ipo injection sí).               |
| `PII_RESPONSE_SANITIZATION` / `_MODE` | `pii-masker` (downstream) | Ń ṣàkóso ìhùwàsí masker ní ẹ̀gbẹ́ èsì.                                                        |

Àwọn guardrail Modality Bridge ń ka ìṣètò àsìkò-ìṣiṣẹ́ láti ibi ìpamọ́ àwọn ìṣètò
tí DB ń ṣe àtìlẹ́yìn fún (`getSettings()`), kì í ṣe láti inú env vars. Àwọn kọ́kọ́rọ́ àkọ́kọ́ ti Vision ni
`modalityBridgeVisionEnabled`, `modalityBridgeVisionMode`,
`modalityBridgeVisionModel`, `modalityBridgeVisionTaskAware`,
`modalityBridgeVisionPrompt`, `modalityBridgeVisionTimeout`,
`modalityBridgeVisionMaxImages`, `modalityBridgeVisionMaxChars`,
`modalityBridgeCacheEnabled`, `modalityBridgeCacheTtlMinutes`, àti
`modalityBridgeCacheMaxEntries`. Àwọn kọ́kọ́rọ́ àtijọ́
`visionBridge*` ni a gbà nìkan gẹ́gẹ́ bí fallback kíkà fún ìyípo kan tí a ti ṣàkọsílẹ̀ rẹ̀;
dashboard máa ń kọ nípa lílo àwọn kọ́kọ́rọ́ àkọ́kọ́. Àwọn iye àiyípadà àkọ́kọ́ àti resolver fallback
wà nínú `src/shared/constants/modalityBridgeDefaults.ts`, nígbà tí a ṣì pa
àwọn constant àtijọ́ mọ́ sínú `src/shared/constants/visionBridgeDefaults.ts`.

Audio ń lo `modalityBridgeAudioEnabled`, `modalityBridgeAudioModel`,
`modalityBridgeAudioTimeout`, àti `modalityBridgeAudioMaxClips`, papọ̀ pẹ̀lú àwọn ìṣètò
`modalityBridgeCache*` tí gbogbo wọn ń pín. Audio kò ní fallback kọ́kọ́rọ́ àtijọ́ nítorí pé
a ṣàfikún àwọn kọ́kọ́rọ́ wọ̀nyí pẹ̀lú schema Modality Bridge.

Video ń lo `modalityBridgeVideoEnabled`, `modalityBridgeVideoAnalysisMode`,
`modalityBridgeVideoModel`,
`modalityBridgeVideoFrameCount`, `modalityBridgeVideoSamplingPolicy`,
`modalityBridgeVideoMaxVideos`, àti
`modalityBridgeVideoTimeout`, papọ̀ pẹ̀lú àwọn ìṣètò `modalityBridgeCache*` tí gbogbo wọn ń pín.
A pa á ní àiyípadà àkọ́kọ́ nítorí pé FFmpeg/ffprobe jẹ́ àwọn dependency ìṣiṣẹ́ tí kò pọndandan,
àti pé fífi caption sí àwọn frame ń mú ìdádúró àti iye owó model pọ̀ sí i.

## Àwọn Guardrail Àkànṣe

```typescript
import { BaseGuardrail, guardrailRegistry } from "@/lib/guardrails";

class BudgetGuardrail extends BaseGuardrail {
  constructor() {
    super("budget", { priority: 50 });
  }

  async preCall(payload, ctx) {
    if (ctx.apiKeyInfo?.budgetExceeded) {
      return { block: true, message: "Daily budget exceeded" };
    }
    return { block: false };
  }
}

guardrailRegistry.register(new BudgetGuardrail());
```

Àwọn ìgbésẹ̀:

1. Ṣẹ̀dá `src/lib/guardrails/myGuardrail.ts` tí ó fa `BaseGuardrail` gbòòrò.
2. Ṣe àmúṣẹ `preCall` àti/tàbí `postCall`.
3. Yálà forúkọsílẹ̀ ní àkókò import (ṣe push láti `registerDefaultGuardrails`) tàbí
   pe `guardrailRegistry.register(...)` ní runtime — registry náà máa rọ́pò
   guardrail èyíkéyìí tó wà tẹ́lẹ̀ pẹ̀lú orúkọ normalized kan náà.
4. Ṣàfikún àwọn ìdánwò sábẹ́ `tests/unit/` (àwọn àpẹẹrẹ tó wà:
   `tests/unit/guardrails-registry.test.ts`,
   `tests/unit/prompt-injection-guard.test.ts`,
   `tests/unit/guardrails/visionBridge.test.ts`).

## Ìdánwò

Lo `resetGuardrailsForTests()` láàárín àwọn ìdánwò láti bẹ̀rẹ̀ láti ipò tí a mọ̀.
Fi `{ registerDefaults: false }` ránṣẹ́ láti bẹ̀rẹ̀ pẹ̀lú registry òfìfo, kí o sì
forúkọsílẹ̀ àwọn guardrail tí a ń dánwò nìkan. Vision Bridge gba dependency
injection (`deps.getSettings`, `deps.callVisionModel`); Audio Bridge sì pèsè àwọn
ọ̀nà ìsopọ̀ tó bá a mu fún àwọn ààtò, àwọn agbára, yíyan model STT, àyẹ̀wò credential,
àti transcription. Nítorí náà, àwọn ìdánwò lè ṣe àyẹ̀wò àwọn flow méjèèjì láìní
àyè sí DB tàbí network.

## Ìbora route injection-guard àti red-team (Phase 8 · Block D)

Injection-guard (`createInjectionGuard` / `withInjectionGuard`) bo gbogbo àwọn route
tó gba àwọn prompt olumulo. Ó tẹ̀lé `INJECTION_GUARD_MODE` (default `warn` = log nìkan;
`block` = dá HTTP 400 `SECURITY_001` padà).

| Irú         | Àwọn Route                                                                                                                                           | Mode default |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| Ọ̀rọ̀ (tó wà) | `/v1/chat/completions`, `/v1/completions`, `/v1/relay/chat/completions`                                                                              | warn         |
| Ìṣẹ̀dá       | `/v1/messages`, `/v1/responses`, `/v1/images/generations`, `/v1/images/edits`, `/v1/videos/generations`, `/v1/music/generations`, `/v1/audio/speech` | warn         |
| Dátà        | `/v1/embeddings`, `/v1/rerank`, `/v1/search`, `/v1/moderations`                                                                                      | warn         |

Yíyọ ọ̀rọ̀ jáde (`extractMessageContents`) bo `messages`/`input`/`prompt`/`query`+`documents`/`instructions`/`system`.

**Red-team (lóru gbogbo ọjọ́, `nightly-llm-security.yml`):** promptfoo fìdí rẹ̀ múlẹ̀ pé route kọ̀ọ̀kan ń dènà
corpus OWASP-LLM nínú `INJECTION_GUARD_MODE=block`; garak ń ṣiṣẹ́ àwọn probe (ó máa foju kọ ọ́ láìsí secret).
`moderations` wà nínú rẹ̀ fún ìṣọ̀kan — àwọn operator nínú block-mode lè yọ ọ́ kúrò nípasẹ̀
`resolveDisabledGuardrails`.

Workflow alẹ́ náà (`.github/workflows/nightly-llm-security.yml`, cron + manual
dispatch) ní job méjì:

- **`promptfoo-guard` (tó ń dènà)** — ń ṣiṣẹ́ `promptfoo eval -c promptfooconfig.yaml`
  pẹ̀lú `INJECTION_GUARD_MODE=block`. Case adversarial kọ̀ọ̀kan (fún àpẹẹrẹ, "foju kọ gbogbo
  àwọn ìtọ́ni iṣáájú…", àwọn jailbreak irú DAN) ń ṣàyẹ̀wò pé response náà ní
  `error.code === "SECURITY_001"`, ìyẹn ni pé guard náà kọ request náà ní ti gidi.
- **`garak` (ìmọ̀ràn)** — ń ṣiṣẹ́ garak `--probes promptinject,dan,leakreplay`
  lòdì sí instance OmniRoute local kan (`http://localhost:20128/v1`). Ó dá lórí
  secret provider kan (`PROMPTFOO_PROVIDER_KEY`); ó máa foju kọ ọ́ lọ́nà tó bójú mu, a sì fi
  `|| true` sí òpin rẹ̀, nítorí náà ó ń ṣe report láìfa ìkùnà CI.

Ìbora helper guard náà (`createInjectionGuard` / `withInjectionGuard`)
nà dé gbogbo route `/v1` tó ní prompt; a ń fa ọ̀rọ̀ prompt jáde láti inú
`messages`/`input`/`prompt`/`query`+`documents`/`instructions`/`system` nípasẹ̀
`extractMessageContents()` nínú `src/shared/utils/inputSanitizer.ts`.
